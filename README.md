# ElasticLog 📊

ElasticLog is a web server log search and analytics platform that helps analyze server traffic, monitor errors, and detect suspicious activity through an interactive dashboard.

## 🌐 Live Demo

[Explore ElasticLog](YOUR-DEMO-LINK)

## Features

- Parse Apache, Nginx, and JSON logs.
- Search and filter server logs.
- Monitor traffic, errors, and response times.
- Visualize analytics through interactive charts.
- Detect suspicious requests and traffic spikes.
- Generate and simulate server traffic.
- View live log updates.
- Export results as JSON or CSV.
- Supports real Elasticsearch and an embedded in-memory engine.

## Tech Stack

- Node.js
- JavaScript
- Elasticsearch
- Chart.js
- Python

## Run Locally

```bash
git clone https://github.com/YOUR-USERNAME/ElasticLog.git
cd ElasticLog
node server.js
```

Open `http://localhost:3000` in your browser.
